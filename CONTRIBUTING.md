# Contributing

This repository is currently published as a reference implementation. We're
not accepting external pull requests at this stage - the codebase is
evolving rapidly and we don't yet have the bandwidth to triage and review
incoming contributions to the standard we hold ourselves to.

If you find a bug or have a feature suggestion, please open an issue and
we'll consider it during planning. If you'd like to discuss a substantive
change, please open an issue first so we can talk through fit and timing
before any code lands.

For security issues, follow [`SECURITY.md`](./SECURITY.md). **Please do not
open a public issue for security reports.**

If we open contributions in the future, the workflow will be:

1. Discuss the change in an issue first.
2. Sign the contributor agreement (a one-time DCO sign-off on commits).
3. Open a pull request against `main`.
4. The PR will be reviewed against the global UX design standard at
   [`docs/standards/ux-design-standard.md`](./docs/standards/ux-design-standard.md).
5. Automated checks (lint, typecheck, unit tests, E2E, accessibility) must
   pass.
6. Two maintainer approvals required.

Thanks for your interest.
